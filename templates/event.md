# Template: Event

## When to use
Concerts, workshops, launches, pop-ups, fairs, parties.

## Style block
```
STYLE: Event poster.
- Atmospheric background that matches the event mood (stage lights, gradients, textures).
- Product or key visual large, with a subtle glow or rim light.
- Date, time and venue clearly grouped in a dedicated block, easy to scan.
- Expressive display typeface for the headline, simple sans-serif for details.
- Optional ticket-style or badge element for price or "Free entry".
```

## Example brief
- Product: Pop-up market for local makers
- Headline: Made by hand
- Subheadline: Sat 14 June, 11:00-20:00, Old Mill Yard
- CTA: Free entry
- Tone: Warm, creative
- Format: Vertical 3:4
